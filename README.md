# ⚽ مبلمان پرنس بیرجند — وب‌سایت باشگاه فوتسال

نسخهٔ **سوپر گرافیکی / سوپر انیمیشنی** وب‌سایت باشگاه فوتسال مبلمان پرنس بیرجند.
کاملاً استاتیک (HTML/CSS/JS خالص) — بدون نیاز به بیلد یا سرور خاص؛ کافی است فایل‌ها را روی هر هاستی بگذارید.

## 🛠️ نکات فنی

- **بدون هیچ وابستگی خارجی:** فونت‌آوسام (در `css/fontawesome.min.css` + پوشه `webfonts/`) و فونت‌های پیکان/دوران به‌صورت لوکال‌اند؛ سایت حتی آفلاین و بدون CDN هم کامل کار می‌کند.
- احترام به `prefers-reduced-motion`، ناوبری با کیبورد و فوکوس قابل مشاهده.
- ریسپانسیو کامل (موبایل ۳۹۰px تا دسکتاپ) — تست‌شده با مرورگر واقعی.

## ✏️ ویرایش سریع

- **مربی‌ها:** در `index.html` بخش `#coaches` — عکس‌ها در `img/` (هر سه عکس فعلی یکی‌اند؛ برای هر مربی عکس خودش را جایگزین کنید).
- **بازی‌ها:** بخش `#matches` — بازی‌های کوچک با `data-days` (چند روز دیگر) و `data-hour` تاریخ شمسی خودکار می‌گیرند. بازی بزرگ همیشه «۷ روز دیگر ساعت ۱۸» است و در `localStorage` مرورگر کاربر ذخیره می‌شود.
- **جدول لیگ / نتایج:** متن سادهٔ HTML در همان بخش.
- **عکس‌های گالری:** پوشهٔ `img/` (`gallery-*.jpg`) + عکس تیمی واقعی `hero-bg.jpg`.
- **ثبت‌نام‌ها کجا ذخیره می‌شوند؟** فعلاً در `localStorage` مرورگر با کلید `prince_players` (سازگار با کلید قبلی `prince_futsal_players`). برای اتصال واقعی به پنل/SMS، تابع submit در `js/script.js` را به API خودتان وصل کنید.
